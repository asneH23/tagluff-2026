# Tågluff 2026 🚂

En mobilanpassad resehemsida för tågluffandet genom Europa, 2–16 aug 2026.

**Gänget:** Aston, Molle (the Gaffer), Jacob, Cesar, Ivar

## Funktioner
- 🗺️ Interaktiv karta med rutt och stopp
- ✅ Delad checklista (Eurail-kort, packlista, etc.)
- 📍 Aktiviteter & boenden per stad
- 🔄 Realtidssynk via Firebase Firestore

## Tech
- HTML / CSS / Vanilla JS
- [Firebase Firestore](https://firebase.google.com/) — realtidsdatabas
- [Firebase Hosting](https://firebase.google.com/products/hosting) — publicering
- [Leaflet.js](https://leafletjs.com/) — interaktiv karta

## Lokal utveckling
Öppna bara `index.html` i en webbläsare.

## Deploy
```bash
npx firebase-tools deploy
```
